# OmniFloat

Lanzador flotante minimalista con **Glassmorphism en vivo**, barra de búsqueda rápida (`Alt + Espacio`), calculadora integrada e **Isla Flotante (HUD)** de monitoreo de sistema.

## 📥 Descarga Directa (Sin compilar código)

Puedes descargar el ejecutable listo para usar directamente desde **GitHub Releases**:

- 🪟 **Windows (64-bit Portable `.exe`)**: [**Descargar `omnifloat-windows-amd64.exe`**](https://github.com/rac-developer/omnifloat/releases/latest/download/omnifloat-windows-amd64.exe)
- 📦 **Windows (`.zip`)**: [**Descargar `omnifloat-windows-amd64.zip`**](https://github.com/rac-developer/omnifloat/releases/latest/download/omnifloat-windows-amd64.zip)
- 🐧 **Linux (`.deb` / `.tar.gz`)**: [**Ver todos los archivos en Releases**](https://github.com/rac-developer/omnifloat/releases/latest)

---

## 🚀 Uso rápido

1. Descarga y ejecuta `omnifloat-windows-amd64.exe` (o `omnifloat.exe`).
2. Presiona **`Alt + Espacio`** en cualquier momento para abrir o cerrar el buscador flotante.
3. Haz clic derecho sobre el icono en la **bandeja del sistema (System Tray)** o sobre la **Isla Flotante** para abrir la configuración.

---

## 🛠️ Compilar desde el código fuente (Opcional)

Si deseas compilar el proyecto manualmente en Windows:

```powershell
.\build.ps1
```

El ejecutable se generará en `build/bin/omnifloat.exe`.
